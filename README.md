# Biblioteca Personal

Aplicación web CRUD para gestionar una colección de libros.

## Descripción

Biblioteca Personal permite registrar, visualizar, editar y eliminar libros mediante una interfaz web sencilla.

El proyecto utiliza LocalStorage para almacenar los datos directamente en el navegador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage
- Git
- GitHub

## Funcionalidades

- Registrar libros
- Visualizar libros registrados
- Editar información de libros
- Eliminar libros
